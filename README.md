# Docker Web App

A showcase of Docker, FastAPI, MongoDB, and Apache ECharts. This app allows users to submit data via a REST API, store it in MongoDB, and visualize it interactively using ECharts.

## Prerequisites
- Docker
- Docker Compose

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/pjlau/docker_webapp
   cd docker_webapp

2. Run the app:
   ```bash
   docker compose up --build

3. Check the app in the browser:
   ```bash
   http://localhost:8000
